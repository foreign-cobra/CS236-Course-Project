CS 236 311 Integration Project
Windows + WSL Setup, GitHub, and Run Guide

This guide sets up the project on Windows using WSL 2 (Ubuntu) for PySpark.

Expected input files in the project folder:
  nyc_311_800k.csv
  la_311_800k.csv

Install a linux distribution (preferably the latest version of Ubuntu)
wsl --install -d Ubuntu-24.04

Select the distribution
wsl -d Ubuntu-24.04

INSTALL PYTHON, JAVA, AND GIT INSIDE UBUNTU

In the terminal...
sudo apt update
sudo apt install -y python3 python3-venv python3-pip openjdk-17-jdk git

Confirm...
python3 --version
java -version
git --version

CREATE AND ACTIVATE A PYTHON VIRTUAL ENVIRONMENT

mkdir -p ~/.venvs
python3 -m venv ~/.venvs/cs236
source ~/.venvs/cs236/bin/activate
python -m pip install --upgrade pip
python -m pip install pyspark==3.5.1

Verify PySpark

python -c "import pyspark; print('PySpark:', pyspark.__version__)"

Expected version: 3.5.1.

source ~/.venvs/cs236/bin/activate

python -m pip install -r requirements.txt

Confirm pyspark is still 3.5.1

From here on out you should be able to run the scripts in the directory using...

python "script_name"

All scripts have a different purpose. Look here:

spark_smoke_test.py - Run this to check if spark is up and running. 
eda_schema.py - Runs an analysis both datasets, check each column, different values, and column frequency. 
clean_datasets.py - Runs through both datasets and sets corrupted values to null
prepare_merge_ready.py - Creates the cleaned datasets with renamed columns, dropped columns, in parquet form.
combine_merge_ready.py - Combines the parquet files generated by the previous merge_ready script into one, single parquet file. 
read_clean_datasets.py - Reads the first few rows of both datasets.
merge_datasets.py — Combines the datasets into one Parquet dataset and checks that all records and values are correct.
