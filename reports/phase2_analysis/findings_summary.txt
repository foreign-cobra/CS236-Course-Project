Methods and output files:
  Weekly counts use calendar-month periods: days 1-7, 8-14, 15-21, and 22-end.
  Postal code percentages use all requests in that city/postal code as denominator, including missing request types.
  Status categories are those standardized upstream to Open, Pending, and Closed (with original cancelled values included in Closed); null/unmapped statuses are reported as unknown.
  Channel groups align clear equivalents: ONLINE/Self Service, PHONE/Call, and MOBILE/Mobile App; other labels are normalized for case and spaces and retained.
  Detailed tables are saved as headered CSV output folders in this directory.
